# sound.mix リファレンス

dviavi の音を書くファイル。楽器と声を定義し、トラックの上にクリップ（MML の演奏、声の歌唱、音声ファイル）を
動画の時刻に置く。`\dviaviSetup{mix=sound.mix}` で指定する（[dviavi.md](dviavi.md)）。

```
% 熱異常 inst 版の例
inst lead { wave=triangle adsr=4ms,60ms,0.85,40ms gain=-16dB }
inst harm { wave=sine adsr=8ms,80ms,0.7,60ms gain=-23dB }
voice example { f0=200 mora=150ms formant=1.1
  tone normal { f0x=1 range=4st }
  tone happy  { f0x=1.15 range=7st } }

track melody pan=-0.2
  @11.1475s lead q8 t183 o5c+8 o5c+8 o5g+4
    o5f+8 o5e8                         % 次の @ までは直前のクリップの続き
track se gain=-6dB
  @intro+12f file "boom.wav" gain=-3dB
track vocal
  @chorus example t120 o4 l8 "KoNnNiTiWa" c d e f g2
```

## 書式

- `%` から行末までコメント（TeX と同じ。MML の `#` はシャープなので使わない）。
- `inst 名前 { … }` と `voice 名前 { … }` は定義。`{ }` の中は `key=value` の並びで、複数行にわたってよい。
- `track 名前 [gain=… pan=…]` 以降の `@…` 行がそのトラックのクリップ。`track` より前のクリップは `main` トラックに入る。
- `@` で始まる行が 1 つのクリップ。続く行のうち `@`、`inst`、`voice`、`track` で始まらないものは、直前の MML クリップの続き。
- 行頭の空白（字下げ）は意味を持たない。

エラーは `sound.mix:行: 内容` で報告し、変換を止める。クリップの中の MML の誤りは警告してそのクリップだけ飛ばす。

## 時刻

クリップの開始時刻（`@` の直後）に書けるもの:

| 書き方 | 意味 |
|---|---|
| `12f`, `12` | フレーム（単位なしもフレーム） |
| `1.5s`, `150ms` | 秒、ミリ秒 |
| `1:23.5` | 分:秒 |
| `intro` | `\dviaviMark{intro}` を置いたフレーム |
| `intro+12f`, `intro-1s` | マークからの相対時刻（`+`/`-` の後は上の長さの書き方） |

時刻 0 は最初のフレームの始まり。フレームはそのページの `fps` で秒に換算する。
0 より前に始まるクリップは警告して飛ばす。マーク名には英字・数字・`_` を使う（`-` は相対時刻と紛れる）。

## 値の書き方

| 種類 | 例 |
|---|---|
| 周波数 | `440`, `440Hz`, `2k`, `2kHz` |
| ゲイン | `-6dB`（デシベル）または `0.5`（倍率） |
| 音程の幅 | `3c`（セント）、`4st`（半音） |
| 長さ（楽器・声のパラメータ） | `5ms`, `0.2s`（フレームでは書けない。フレームレートに依存させないため） |

## inst（楽器）

```
inst 名前 { wave=… duty=… adsr=a,d,s,r gain=… detune=… lpf=… vib=速さ,深さ }
```

| キー | 既定値 | 意味 |
|---|---|---|
| `wave` | `sine` | `sine`, `square`, `triangle`, `saw`（`sawtooth`）, `noise`（ホワイトノイズ） |
| `duty` | `0.5` | 矩形波のデューティ比（0.01〜0.99） |
| `adsr` | `5ms,50ms,0.8,50ms` | アタック, ディケイ, サステインのレベル（0〜1）, リリース |
| `gain` | `0.5` | 音量 |
| `detune` | `0c` | 重ねる発振器ごとのずれ（`0c,7c` で 2 つ重ねる）。音量は発振器数で割る |
| `lpf` | なし | 2 次のローパスフィルタの遮断周波数 |
| `vib` | なし | ビブラート（`5Hz,10c`） |

- 矩形波・鋸歯波・三角波は帯域制限して作る（高い音でも折り返し雑音が出にくい）。
- 波形名（`sine` `square` `triangle` `saw` `noise`）は定義しなくてもそのまま楽器名として使える（上の既定値）。
  同じ名前で `inst` を定義すれば、そちらが優先する。
- ノイズは打楽器（ハイハットなら `wave=noise adsr=1ms,25ms,0,15ms lpf=12k`）や効果音に。

## voice（声）

```
voice 名前 { f0=… mora=… formant=… breath=… gain=… vib=速さ,深さ engine=… lang=…
  tone 名前 { f0x=… range=… } … }
```

| キー | 既定値 | 意味 |
|---|---|---|
| `f0` | `140` | 基本周波数（声の高さ） |
| `mora` | `150ms` | `\speak` の `pace=1` のときの 1 モーラの長さ |
| `formant` | `1` | フォルマント周波数の倍率（声色。1.1〜1.2 で高い声らしくなる） |
| `breath` | `0.03` | 息の雑音の量 |
| `gain` | `0.5` | 音量（1 回の発話・1 クリップごとに最大振幅をこの値にそろえる） |
| `vib` | `5.5Hz,12c` | ビブラート |
| `engine` | `formant` | 有声音の作り方: `formant`（声帯音源＋共振器）か `square`（矩形波のフォルマント） |
| `lang` | `ja` | 歌詞・`\speak` の書き方の既定: `ja`（ローマ字）か `en`（ARPAbet）。クリップと `\speak` の `lang=` が優先 |
| `tone 名前 { f0x= range= }` | `f0x=1 range=4st` | 話し方。`f0x` は高さの倍率、`range` は抑揚の幅 |

声は声帯音源（帯域制限した鋸歯波＋息の雑音）をフォルマントの共振器（F1〜F3 と固定の F4）に通し、
口の放射特性を掛けて作る。子音のノイズ（破裂・摩擦）は帯域通過フィルタを通した雑音を足して作る。
音素の切り替わりではフォルマントと高さがなめらかに動く（子音のフォルマントが次の母音への出発点になる）。

`engine=square` では、F1〜F3 をそれぞれその周波数の矩形波にする。矩形波は声の周期ごとに位相 0 から鳴り直し、
帯域幅で減衰する（exp(−π·bw·t)、大きさは F1:F2:F3 = 1 : 0.5 : 0.25）。昔の音声合成チップのような声になる。
子音の雑音・音素・高さの動きは `formant` と同じ。

`\speak` の抑揚は東京式の単純なもの: 句の最初のモーラが低く、次から高く、アクセント核（`'`）の後は低い。
発話全体で 1 半音下がっていく。

### 音素とモーラ

ローマ字のモーラは音素に分かれる: `Ka` → k a、`Shi`/`Si` → sh i、`Kya` → k y a、`Tsu`/`Tu` → ts u、`Chi`/`Ti` → ch i、
`Fu`/`Hu` → f u、`Ji`/`Zi` → j i、`Nn` → N（ん）、`Q` → 無音（っ）、`-` → 直前の母音、`_` → 休み。

| 音素 | 種類 | | 音素 | 種類 |
|---|---|---|---|---|
| `a i u e o` | vowel | | `s sh h f` | fricative（摩擦） |
| `N` `N:m` `N:n` `N:ny` `N:ng` | nasal（ん） | | `z j ch ts` | affricate（破擦） |
| `k g t d p b` | stop（破裂） | | `m n` | nasal |
| `r` | flap（はじき） | | `y w` | glide（わたり） |

- **英語**（`lang=en`）: 1 音節を ARPAbet の音素を `.` でつないで書く（`D.EY`、`S.W.IY.T`、`K.AH.L`）。
  母音の前がオンセット、最初から最後の母音までが核、その後がコーダになる。二重母音は 2 つの目標に分ける
  （`EY` → EH IY、`AY` → AA IH、`OW` → AO UH、`AW` → AA UH、`OY` → AO IY。核の 60% と 40%）。
  日本語と共通の子音（`K` `G` `T` `D` `P` `B` `S` `SH` `HH` `F` `CH` `JH` `M` `N` `W` `Y`）は日本語の音素を使い、
  英語だけのものとして母音 `IY IH EH AE AH AA AO UH UW ER` と子音 `V TH DH Z ZH NG L R` がある（`phoneme` で調整できる）。
  `-` は直前の母音を伸ばし、`_` は休み。
- **ん**は後ろの音に同化する: p b m の前で `N:m`（[m]）、t d n ts z r の前で `N:n`（[n]）、ch j の前で `N:ny`（[ɲ]）、
  k g の前で `N:ng`（[ŋ]）、母音・y・w・s・h・f の前と発話の終わりで `N`（[ɴ]・鼻母音）。
  どれも低い第 1 鼻音フォルマント（m から ŋ に向かって高くなる）と、帯域を広げて弱めた上のフォルマントを持つ鼻音で、モーラいっぱいに続く。
- **話す**（`\speak`）: 子音はモーラの頭に置く（モーラの 60% まで）。モーラの最後の音素（母音・ん・休み）が残りを埋める。
- **歌う**（声の MML クリップ）: 母音を音符の頭に合わせ、子音はその前に置く（UTAU の先行発声と同じ）。
  前の音符の母音はそこで切れる。子音は前の音符の始まりからの時間の半分までに縮める。
  英語のコーダ（`S.W.IY.T` の t）は音符の終わりに置く（音符の 40% まで）。

### phoneme（音素の調整）

```
phoneme k { closure=30ms dur=20ms noise=-4dB noisef=2800 }      % 全部の声
voice vocal { f0=220 formant=1.12
  phoneme s { noise=0.45 noisef=7000 }                           % この声だけ
  phoneme a { f=850,1250,2600 } }
```

組み込みの値に、トップレベルの `phoneme`、声の中の `phoneme` の順に上書きする（書いたキーだけが変わる）。
新しい名前を付けると新しい音素になる（既定は母音）。

| キー | 意味 |
|---|---|
| `kind` | `vowel` `nasal` `stop` `fricative` `affricate` `flap` `glide` `silence` |
| `f` | F1,F2,F3（Hz）。母音の目標、子音では自分の共鳴と次の母音への出発点 |
| `bw` | フォルマントの帯域幅（Hz） |
| `amp` | 有声音の大きさ（母音・鼻音・はじき・わたり） |
| `voiced` | 子音の閉鎖・雑音のあいだの声帯振動（0〜1。g d b z j で 0.5 前後） |
| `noise`, `noisef`, `noisebw` | 雑音の大きさ（倍率か `dB`）、中心周波数、帯域幅（Hz） |
| `noise2`, `noise2f`, `noise2bw` | 2 つ目の雑音帯域: 大きさ（`noise` に対する倍率か `dB`）、中心、幅。`noise` と同じ時間変化で鳴る |
| `closure` | 子音の前の無音（閉鎖）の長さ（`ms`/`s`） |
| `dur` | 子音そのもの（破裂・摩擦・鼻音など）の長さ |
| `aspiration`, `aspamp` | 破裂音: 破裂の後の気息の長さと大きさ（k t p）。気息は声道を通る雑音（フォルマントは次の母音へ動く）で、狭めの帯域の雑音も 10 dB ほど下がって続く |
| `pinch` | 破裂音: 0〜1。破裂の雑音の中心を次の母音の F2 の少し上に寄せる度合い（軟口蓋の k g で 1） |

破裂の雑音は `dur` を時定数として減衰する（`dur` のあいだに約 9 dB）。k の既定値は実際の発声の測定に合わせてある:
破裂は次の母音の F2 の少し上（「か」で約 1.5 kHz）の幅の狭い帯域（`noisebw=250`）、強い部分が 20 ms、その後 50 ms の気息。
それに約 4.7 kHz・幅 500 Hz の高い帯域が 20 dB 下で加わる（`noise2=0.07`）。

調整には次の 2 つを使う:

- **`dviavi say`**（本物のエンジン）: `dviavi say --mix vocal.mix --voice vocal --play "KaKiKuKeKo"`、
  歌は `--sing 't120 o4 l8 "KaKiKu" c d e'`。WAV に書き出す（`-o`）。[dviavi.md](dviavi.md#dviavi-say)
- **ボイスチューナー**（`tools/voice-tuner.html`）: ブラウザでスライダーを動かしながら聞き、変えた音素だけを
  `phoneme` 行として書き出す。合成は dviavi と同じ計算（同じ入力で波形が一致する）。既存の mix ファイルを貼り付けて読み込める。

## track と clip

```
track 名前 [gain=… pan=…]
  @時刻 楽器または声 [gain=…] MML…
  @時刻 file "パス" [gain=…]
```

| キー | 既定値 | 意味 |
|---|---|---|
| track の `gain` | `1` | トラック全体の音量 |
| track の `pan` | `0` | 定位（-1 = 左, 1 = 右） |
| clip の `gain` | `1` | そのクリップの音量 |
| clip の `lang` | 声の `lang` | 歌詞の書き方（`ja` / `en`） |

- **MML クリップ**: 名前が `inst`（または波形名）なら演奏、`voice` なら歌う。名前の直後の `key=value` はクリップのパラメータ、
  それ以降が MML。
- **歌唱**: MML の中の `"…"` が歌詞。ローマ字で、大文字がモーラの先頭（`\speak` と同じ）。
  後に続く音符に 1 モーラずつ割り当てる。`|` で区切ると区切りごとに 1 音符になる（`"DeI|Ji-"` は「デイ」「ジー」の 2 音符、
  1 音符の中のモーラは音符を等分する）。英語（`lang=en`）は空白か `|` で区切った 1 音節ずつ（`"D.EY Z.IY"`）。
  歌詞のない音符は直前の母音を伸ばす（最初なら「あ」）。
  UST からは `tools/ust2dviavi.py mix --lyrics` で、歌詞付きのクリップを作れる。
- **ファイル**: パスは sound.mix のあるディレクトリから見る。サンプリング周波数が同じ WAV（8/16/24/32 bit 整数、32 bit 浮動小数点、
  モノラルかステレオ）は直接読む。それ以外の形式や周波数のものは `ffmpeg` で（パイプ経由で）デコードする。

## MML

| 書き方 | 意味 | 既定 |
|---|---|---|
| `c d e f g a b` | 音符。`+` か `#` でシャープ、`-` でフラット（重ねてよい） | |
| 長さ | 音符の後の数字。`4` = 4 分音符、`8.` = 付点 8 分（点は重ねてよい）、`3` `12` `96` などの半端な値も可 | `l` の値 |
| `&` | タイ（`c4&c16` または `c4&16`） | |
| `r` | 休符（長さの書き方は音符と同じ） | |
| `<c e g>4` | 和音（中の音符には長さを書かない） | |
| `"KoNnNi"` | 歌詞（声のクリップで使う） | |
| `t数` | テンポ（4 分音符 / 分） | `t120` |
| `o数`, `o+`, `o-` | オクターブ（`o4c` が中央のド = MIDI 60）、相対変更 | `o4` |
| `l長さ` | 長さを省いた音符・休符の長さ（`l8.` も可） | `l4` |
| `v数` | ベロシティ（0〜127） | `v100` |
| `q数` | ゲート（音を出す長さ、1〜8 の 8 分率。`q8` で次の音符まで切れ目なし） | `q7` |
| `\|`、空白 | 無視（小節線などの目印に） | |

和音は `<` `>` で書くので、オクターブの上下は `>` `<` ではなく `o+` `o-` で書く。

## 混ぜ方

- 全トラックのクリップ、`\speak` と `\dviaviTone`（中央に定位）を 1 つのステレオバッファに足し合わせる。
- モノラルの音（楽器・声）は等パワーの定位、ファイルの音（ステレオ）はバランスで `pan` を掛ける。
- 最後に、振幅 0.8 を超える部分をなめらかに抑える。1.0 を超えていた場合は「audio peak … soft-clipped」と警告するので、
  各 `gain` を下げる。
- 長さは動画と同じ。最後のフレームより後の音は切れる。
